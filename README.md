# Sales Dashboard – Power BI

## Project Overview
This project is an interactive sales dashboard built in Microsoft Power BI. It presents key sales metrics and visual summaries to help explore sales performance across dates and business dimensions.

## Dashboard Features
- **Revenue KPI** to monitor total revenue.
- **Sales Quantity KPI** to monitor the quantity sold.
- **Charts and trend visuals** for exploring sales patterns and comparisons.
- **Date filters** including year and date selection, so users can focus on a specific period.

## Data Model
The Power BI model includes the following tables:
- `sales transactions`
- `sales products`
- `sales customers`
- `sales markets`
- `sales date`
- `BaseMeasures`

## Tools Used
- Microsoft Power BI Desktop
- Power Query / data modelling (where applicable)

## How to View the Dashboard
1. Download `Dasboard.pbix` from this repository.
2. Open the file using **Power BI Desktop**.
3. Use the date slicers to filter the dashboard.
4. Explore the KPI cards and charts to review the sales information.
